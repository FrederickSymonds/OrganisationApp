# OrganisationApp

OrganisationApp is a personal organisation system built around the idea
that life requires direction, and so life is is aimed at some higher goal.

## The System

OrganisationApp consists of three interconnected systems:

- **Task System:** turns goals into concrete actions.
- **Rule System:** establishes rules for handling situations, habits,
  distractions, and impulses.
- **Review System:** evaluates progress and feeds information back into
  the other two systems.

See System.md for a fuller conceptual model. See architecture.md for model plans.

## Purpose
The purpose of this software is to organise someone's life through my system, in a way that reduces friction as much as possible, Ie, minimal effort for maximum rewards.
